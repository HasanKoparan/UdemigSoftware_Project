## ✨ Features

- 🖥️ Hero section with full-width background image and CTA
- 📧 Newsletter subscription section
- 🛠️ Services page with pricing cards (Website Design, Maintenance, Hosting)
- 📄 About page with Vision, Mission, and Why Us sections
- 📬 Contact form with name, surname, email, phone and message fields
- 🔗 Multi-page navigation (Home, About, Services)
- 📱 Fully responsive layout

---

## 🛠️ Technologies Used

- **HTML5** — Semantic multi-page structure
- **CSS3** — Custom styling and responsive layout
